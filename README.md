A one-line excuse an AI agent gives its human after missing a deadline.
The winning line lives verbatim in `entry.txt`; `main.py` writes those exact bytes to `/output/entry.txt`.
Run `python3 main.py` to write, `python3 main.py --check` to read back and verify the match.
Deterministic, offline, Python 3 standard library only. `research.md` holds the 25-candidate scoring ledger.
